# LightSwitch 发布说明

## v1.1.3.0（2026-10-17）

### 重点修复

- **待机 / 休眠唤醒后壁纸切换失败**：深浅色主题是纯注册表写入，唤醒后能正常切换；但壁纸依赖 `IDesktopWallpaper` COM 接口，唤醒瞬间桌面 shell / DWM 仍在重建，壁纸调用会被 Windows 静默丢弃，且此前调度器只在「主题状态不一致」时才套用壁纸，没有重试路径。现已新增电源恢复事件监听（`SystemEvents.PowerModeChanged`），系统从睡眠 / 休眠唤醒后延迟重新套用主题与壁纸（强制刷壁纸，绕过已同步判断）；同时当唤醒后尚未枚举到活动显示器时回退到全显示器壁纸设置，避免静默跳过。

### 安装

1. 将 `LightSwitch_1.1.3.0_x64.cer` 导入"受信任的根证书颁发机构"（本地计算机）。
2. 双击 `LightSwitch_1.1.3.0_x64.msix` 安装（或运行同目录 `Install.ps1`）。
3. 系统要求：Windows 10 1809+ / Windows 11（x64）。

## v1.1.2.0（2026-10-11）

v1.1.0.0 之后的第一个正式发布版本，包含完整的界面重设计与多项关键修复。

### 重点修复

- **设置窗口打开即崩溃**：XAML 解析期间 `TrayDoubleClickCombo` 的 `SelectionChanged`（由标记中的 `SelectedIndex="0"` 触发）在窗口内容尚未挂载时访问了空引用，导致 XamlParseException。已改为空安全查找，并让导航切换处理器在控件未连接时直接返回。
- **日出日落模式在日落后误切浅色**：设置界面在"应用"时会用隐藏的固定时间选择器（00:00）覆盖日出/日落缓存，导致调度器将全天判定为浅色。现在调度器每次评估都根据经纬度实时重算日出/日落，持久化值仅作显示用途。
- **单显示器却显示"显示器 2"**：`GetMonitorDevicePathCount` 会把失活的虚拟显示适配器残留槽位（如 `MS_0001`）计入显示器数量。现在只统计位于活动桌面拓扑中的真实显示器（路径非空且 `GetMonitorRECT` 查询成功），逐显示器壁纸应用同样跳过幽灵槽位。
- **开机自启从未真正生效**：打包（MSIX）应用直接写 `HKCU\...\Run` 会被重定向到包私有注册表，登录时不会启动。已迁移到官方 `windows.startupTask` 清单扩展 + `StartupTask` API：任务管理器"启动"页可见、可由用户禁用；应用启动时按设置自动对齐状态，升级后自愈；若用户在任务管理器中禁用则尊重用户选择（仅在未打包运行时才使用 Run 键回退）。
- **"跟随夜览"首次启用时颜色反转**：切换到该模式时不再强制立即翻转，而是尊重当前实际主题。

### 自 1.1.0 以来的功能增强

- **Fluent 设置界面重设计**：NavigationView 固定侧边栏（模式 / 应用范围 / 桌面壁纸 / 常规），"常规"移至侧边栏底部，窗口可调整大小，Mica 背景与自定义标题栏，修复最大化时顶部白线。
- **"应用"按钮与脏跟踪**：仅在设置有改动时启用；关闭窗口时若有未保存改动则静默保存。
- **多显示器壁纸**：显示器行数动态获取（不再写死数量），新增"多显示器分别设置壁纸"开关，显示器热插拔时自动重建行。
- **切换主题 Toast 通知**。
- **托盘增强**：菜单实时显示当前主题；双击托盘图标行为可配置（切换主题 / 打开设置）。
- **分区切换动画**：切换导航分区时播放 56px 自下而上滑入 + 淡入动画（Composition 隐式动画，首次打开与每次切换均生效），与 Win11 设置应用切页一致。
- **快捷键冲突提示**：注册失败时通过 Toast 告知被占用的组合键。
- **日志自动归档（轮转）**。

### 安装

1. 将 `LightSwitch_1.1.2.0_x64.cer` 导入"受信任的根证书颁发机构"（本地计算机）。
2. 双击 `LightSwitch_1.1.2.0_x64.msix` 安装（或运行同目录 `Install.ps1`）。
3. 系统要求：Windows 10 1809+ / Windows 11（x64）。

### 已知限制

- 若在任务管理器中禁用了开机自启，应用内开关无法重新启用（Windows 系统限制，需在任务管理器中手动恢复）。
- 从旧版本升级后首次启动会自动重写自启任务状态，无需手动操作。
